# T-SQL Queries Using SQL Server Course

![SQL Server Logo](https://upload.wikimedia.org/wikipedia/commons/8/87/Sql_data_base_with_logo.png)

A comprehensive course covering T-SQL querying using Microsoft SQL Server, from fundamental database concepts to advanced Transact-SQL features.

## Course Description

This repository contains materials and resources for the "T-SQL Queries Using SQL Server" course, designed to take students from database fundamentals to advanced querying techniques. The course covers SQL Server installation, database creation and management, join operations, functions, subqueries, set operators, EERD modeling, SQL Server security, and advanced Transact-SQL features.

## Course Outline

### Module 00: Introduction to SQL Server
- Database Lifecycle
- File-based vs Database Systems
- SQL Server Commands
- Installing SQL Server & SSMS

### Module 01: Database Creation and Management
- Create, backup & restore databases
- Create and update tables
- Database diagrams
- CRUD operations
- Filtering and sorting data

### Module 02: Join Operations and Data Integrity
- Cross, Inner, Outer, and Self Joins
- Joining multiple tables
- SQL data types
- Identity properties
- Foreign key constraints
- NULL handling

### Module 03: Functions, Subqueries, and Set Operators
- Aggregate functions
- GROUP BY with WHERE/HAVING
- Subquery types
- Set operators
- Date/time, string, and mathematical functions
- Conditional logic

### Module 04: EERD and SQL Server Security
- Enhanced Entity-Relationship Diagrams
- SQL Server authentication
- Database schemas
- Authorization and permissions
- Server roles

### Module 05: Transact-SQL
- TOP, NEWID, and object paths
- Data import/export
- Ranking and windowing functions
- MERGE statement
- ROLLUP, CUBE, GROUPING SETS
- PIVOT & UNPIVOT operations

## Prerequisites
- Basic computer literacy
- No prior database experience required (for beginner modules)
- SQL Server and SSMS installed (installation covered in course)
